# FPS 미니게임

`1VS1 Game` 미니게임 모음 중 하나. 1대1 실시간 총격전 미니게임.

## 게임 설명

- 1대1 FPS 대결, 라운드제(3선승, 최대 5라운드)
- 한 라운드는 한쪽이 죽으면 종료, 3선승을 먼저 달성하거나 5라운드를 다 채우면(그때 스코어가 더 높은 쪽이) 승리
- 헤드샷 판정 지원 — 헤드샷을 맞히면 즉시 처치되며 상대방 화면에는 킬캠이 재생됨
- 이동 상태(정지/이동/달리기/공중/앉기)에 따라 탄퍼짐(스프레드)이 달라지는 정확도 시스템
- Photon PUN2 기반 실시간 1대1 대전

## 조작법

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 이동 |
| 마우스 이동 | 시점 회전(좌우 몸통 회전, 상하 카메라 회전) |
| **Shift**(이동 중) | 달리기 — 탄퍼짐이 커져 정확도 하락 |
| **Ctrl** | 앉기 — 이동 속도는 느려지지만 탄퍼짐이 줄어 정확도 상승(정지 중 앉으면 탄퍼짐 0) |
| **Space** | 점프(앉은 상태에서는 불가) |
| 좌클릭(누르고 있기) | 사격(연사, `fireRate` 간격) |

- 공중에 떠 있거나 달리는 중에는 탄퍼짐이 커지고, 멈춰서 조준하거나 앉아서 쏘면 정확도가 크게 올라감

## 구현 방식

씬: `Assets/Scenes/MiniGame1.unity` · 스크립트: `Assets/Scripts/FPS MINIGAME/`(네임스페이스: `FPSMinigame`)

| 스크립트 | 역할 |
| --- | --- |
| `FPSController.cs` | `IPunObservable`로 위치/회전/앉기 상태를 매 프레임 네트워크 동기화. WASD 이동, 마우스 룩, 앉기/점프, 이동 상태 기반 탄퍼짐 계산, 발소리/착지음 재생 |
| `GunController.cs` | 사격 로직. `Physics.RaycastAll`로 헤드/바디/장애물 우선순위 판정(헤드샷 우선), 총알 궤적(트레이서)과 탄흔 데칼을 RPC로 전 클라이언트에 동기화 |
| `PlayerHealth.cs` | 체력/사망 처리 |
| `KillCam.cs` | 헤드샷으로 사망했을 때 가해자 시점 킬캠 연출 |
| `PlayerAnimator.cs` | 이동/사격 애니메이터 파라미터 갱신 |
| `MapGenerator.cs` | 맵(장애물 등) 생성 |
| `MG01Manager.cs` | 라운드/스코어 관리(3선승, 최대 5라운드), 라운드 종료 판정과 리스폰, 미니게임 결과를 상위 `GameManager`에 전달 |
| `ScoreUI.cs` | 스코어/라운드 HUD 표시 |

로컬 플레이어의 몸체 메시는 1인칭 시점에 걸리지 않도록 별도 레이어(`ThirdPersonOnly`)로 분리되어, 본인 카메라에는 보이지 않고 상대방 화면에는 보인다.
