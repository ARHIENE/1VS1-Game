# PK (승부차기) 미니게임

`1VS1 Game` 미니게임 모음 중 하나. 한 명은 키커, 한 명은 골키퍼가 되어 승부차기로 대결하는 1대1 미니게임.

## 게임 설명

- 라운드제 승부차기. 각자 정해진 횟수만큼 키커/골키퍼 역할을 번갈아 수행
- 정규 라운드가 끝나도 동점이면 서든데스로 승부
- 남은 라운드 수로 승패가 이미 갈렸으면 조기 종료
- 키커와 골키퍼 모두 제한시간(10초) 안에 행동을 확정해야 함 — 시간 초과 시 키커는 약한 기본 슛, 골키퍼는 랜덤 구역 선택으로 자동 처리
- Photon PUN2 기반 실시간 1대1 대전

## 조작법

### 키커일 때

1. 공 근처를 마우스로 누른 채 드래그 — 공에서 골대까지 이어지는 슛 궤적을 직접 그림
2. 마우스를 떼면 궤적이 확정되고 파워 게이지가 시작됨
3. **좌클릭 또는 스페이스바**로 게이지를 정지 — 게이지가 정지된 지점이 중앙(Perfect)에 가까울수록 정확도가 높아짐(PERFECT! / GREAT! / MISS!)
4. 정확도가 낮을수록 실제 슛 궤적에 오차가 커져 그린 궤적에서 벗어남

### 골키퍼일 때

- 골대 안 원하는 위치를 **좌클릭** — 클릭한 위치가 속한 1~6번 구역(2행 3열)을 방어 구역으로 선택, 즉시 확정
- 키커의 슛 도착 구역과 골키퍼가 선택한 구역이 같으면 선방, 다르면 골

## 구현 방식

씬: `Assets/Scenes/MiniGame_PK.unity` · 스크립트: `Assets/Scripts/PK MINIGAME/`

| 스크립트 | 역할 |
| --- | --- |
| `PKGameManager.cs` | 턴 순서/점수/서든데스 등 경기 전체 흐름 관리, 역할과 무관하게 항상 같은 고정 카메라 시점 유지 |
| `PKKicker.cs` | 마우스 드래그로 슛 궤적 그리기, 파워 게이지 단계로 전환, 10초 제한(초과 시 약한 기본 슛) |
| `PKPowerGauge.cs` | 클릭/스페이스바로 게이지 정지, Perfect 존과의 거리로 정확도(오차량) 산출 |
| `PKTrajectoryUtil.cs` | 정확도를 바탕으로 원본 궤적에 오차를 적용해 실제 슛 궤적을 생성하는 공용 유틸 |
| `PKBall.cs` | 물리(AddForce) 대신 계산된 궤적을 그대로 따라가는 path-follow 방식으로 이동 |
| `PKGoalkeeper.cs` | 골대 안 클릭 위치 → 1~6구역 변환, 다이빙 애니메이션, 10초 제한(초과 시 랜덤 구역) |
| `PKGoalkeeperCursor.cs` | 골키퍼 화면에만 보이는 반투명 1~6구역 안내 UI(런타임 자동 생성) |
| `PKGoalDetector.cs` | 물리 충돌이 아닌, 실제 슛 궤적의 도착 구역과 골키퍼 선택 구역을 비교해 골/선방 판정 |
| `PKGoalZones.cs` | 골대를 2행 3열 6구역으로 나누는 좌표 계산 공용 유틸 |
| `PKUIManager.cs` | 턴/점수/타이머/결과 등 HUD 전반 관리 |

역할과 무관하게 카메라는 항상 공격자 뒤에서 골대를 보는 고정 시점으로 통일되어 있어, 역할이 바뀌어도 시야가 갑자기 뒤집히지 않음.
